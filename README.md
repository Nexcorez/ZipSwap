# NEXCOREZ

Aplikasi web ringan untuk membuka, meninjau, mengedit, dan mengganti aset di dalam arsip `.ZIP` secara langsung melalui browser di HP maupun PC tanpa perlu ekstrak manual.

## Fitur Utama
- **Buka Arsip & Banyak File:** Mendukung file `.ZIP` maupun pemilihan banyak file sekaligus.
- **Pratinjau & Ganti Media Langsung:** Ganti foto (`PNG`, `JPG`, `WEBP`, `SVG`, `GIF`) dan video (`MP4`, `WEBM`, `MOV`, `OGG`) tanpa merusak nama maupun struktur folder asli.
- **Editor Kode & Teks:** Edit file `HTML`, `CSS`, `JS`, `JSON`, `TXT`, dan `XML` lengkap dengan nomor baris dan tombol simpan cepat.
- **Kelola Struktur Arsip:** Tambahkan file baru ke folder utama maupun subfolder, atau hapus file/folder yang tidak diperlukan.
- **100% Lokal di Perangkat:** Seluruh proses baca dan kemas ulang `.ZIP` berjalan langsung di browser tanpa mengunggah file ke server.
- **Responsif & Mode Gelap/Terang:** Nyaman digunakan di layar ponsel maupun desktop.
